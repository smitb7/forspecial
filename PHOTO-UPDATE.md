# Couple Rewind — photo update

The project now includes the four supplied photos:

- `src/assets/couple-main.jpeg` — featured couple photo, softly blended into the welcome page and used on the story cards.
- `src/assets/vishva1.jpg`, `src/assets/vishva2.jpg`, and `src/assets/vishva3.png` — the three-photo gallery.

## Run locally

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```

The gallery opens each photo in a lightbox, and the layout adapts to mobile screens.
